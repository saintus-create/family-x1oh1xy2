# 6222

Application, responsive pleading, or show cause

There is no filing fee for an application, a responsive pleading, or an order to show cause that seeks to obtain, modify, or enforce a protective order or other order authorized by this division when the request for the other order is necessary to obtain or give effect to a protective order. There is no fee for a subpoena filed in connection with that application, responsive pleading, or order to show cause. There is no fee for any filings related to a petition filed pursuant to Part 4 (commencing with 6300) of this division. _(Amended by Stats. 2021, Ch. 686, Sec. 1. (SB 538) Effective January 1, 2022.)_
