# Support

## Section 3692

<div class="source-note">Back to <a href="/division-9-support">Division 9: Support</a></div>

Limits on set aside; inequity or changed circumstances Notwithstanding any other provision of this article, or any other law, a support order may not be set aside simply because the court finds that it was inequitable when made, 290 nor simply because subsequent circumstances caused the support ordered to become excessive or inadequate.
