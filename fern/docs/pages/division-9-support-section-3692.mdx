# 3692

Limits on set aside; inequity or changed circum-

Notwithstanding any other provision of this article, or any other law, a support order may not be set aside simply because the court finds that it was inequitable when made, nor simply because subsequent circumstances caused the support ordered to become excessive or inadequate. Added by Stats. 1999, Ch. 653, Sec. 6. Effective January 1, 2000.
