# Adoption

## Section 8616

<div class="source-note">Back to <a href="/division-13-adoption">Division 13: Adoption</a></div>

The reference to “persons” has been omitted as surplus. 
See <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=10.">Section 10</a> (singular includes plural). 
In subdivision (b), the reference to “prospective adoptive parent or parents” has been substituted for “party or parties adopting.” 
See <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=8542.">Section 8542</a> (“prospective adoptive parent” defined). 
See also <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=8503.">Section 8503</a> (“adoptive parent” defined). 
[23 Cal.L.Rev.Comm. 
Reports 1 (1993)].
