Background on Section 8422 of Repealed Code
Section 8422 was added by 1988 Cal.Stat. ch. 1199 81.5. The
section restated former Probate Code Section 403 (repealed by 1988
Cal.Stat. ch. 1199 43) without substantive change. For background
on the provisions of this part, see the Comment to this part under the
part heading. [20 Cal.L.Rev.Comm.Reports 1001 (1990)].
