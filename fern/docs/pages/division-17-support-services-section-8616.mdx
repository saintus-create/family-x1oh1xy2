# § 8616 — The reference

The reference
to “persons” has been omitted as surplus.
See Section 10 (singular
includes plural).
In subdivision (b), the reference to “prospective adoptive parent or
parents” has been substituted for “party or parties adopting.”
See
Section 8542 (“prospective adoptive parent” defined).
See also
Section 8503 (“adoptive parent” defined).
[23 Cal.L.Rev.Comm.
Reports 1 (1993)].
