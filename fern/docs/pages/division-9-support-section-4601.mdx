## Section 4601

without substantive change. 
The introductory clause has been omitted as surplus. The term “protective order” has been substitut§ 3100 ed for the references to orders under specific sections formerly in the Civil Code and the Code of Civil Procedure. 
This is not a substantive change, since <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=6218.">Section 6218</a> defines “protective order” to include these orders. 
See also Sections 3011 (factors to be considered in determining best interest of child), 3030 (parent convicted under certain Penal Code provisions not allowed unsupervised visitation with child), 3131 
(action by district attorney where child taken or detained in violation of visitation order); Code Civ. Proc.
