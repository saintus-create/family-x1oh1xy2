# Conciliation Proceedings

## Section 1851.2

<div class="source-note">Back to <a href="/division-5-conciliation">Division 5: Conciliation Proceedings</a></div>

Coordination Each court shall coordinate investigations with the filing of accountings, so that investigators may review accountings before visiting conservatees, if feasible.
