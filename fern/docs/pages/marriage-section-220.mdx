# General Provisions

## Section 220

<div class="source-note">Back to <a href="/marriage">Division 2: General Provisions</a></div>

20(a). 
The definition has been broadened to apply to adoptions of minors and adults. 
The reference in the former law to petitioning for an adoption order has been omitted as surplus. 
The reference to final decrees of adoption has been omitted as surplus. 
See <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=100.">§ 100</a> 
(“order” includes decree, as appropriate). The reference to children is also omitted as surplus. 
See <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=10.">§ 10</a> (singular includes plural). 
[23 Cal.L.Rev.Comm. Reports 1 (1993)].
