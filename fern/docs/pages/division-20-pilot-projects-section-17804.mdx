# 17804. Time frames for process establishment and state

*Pilot Projects*

Time frames for process establishment and state
hearing requirement implementation
Implementation of this section, see subd. (j).
Each local child support agency shall establish the complaint resolution process specified in Section 17800. The
department shall implement the state hearing requirements
specified in Section 17801 no later than July 1, 2001. (Added
by Stats.1999, c. 803 (A.B.472), § 2. Amended by Stats.2001,
c. 759 (S.B.943), § 22, eff, Oct. 12, 2001.)

,
Complaint Resolution by Agency.
