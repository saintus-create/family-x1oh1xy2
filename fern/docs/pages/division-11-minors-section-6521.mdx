# 6521. See also the Comment to Section

*Minors*

See also the Comment to Section
6500 for a listing of provisions relating to property exempt from
enforcement of a money judgment. As to a surviving spouse’s waiver
of rights at death, see Sections 140-147.
Background on Section 6510 of Repealed Code
Section 6510 was added by 1983 Cal.Stat. ch. 842
