# § 3444 — Temporary order enforcing out-of-state visitation

Temporary order enforcing out-of-state visitation
order
<span class="subsec">(a)</span>  Acourt of this state which does not have jurisdiction to
modify a child custody determination may issue a temporary
order enforcing either:
..
<span class="subsec">(1)</span>  A visitation schedule made by a court of another state.
<span class="subsec">(2)</span>  The visitation provisions of a child custody determina-
tion of another state that does not provide for a specific
visitation schedule.
<span class="subsec">(b)</span>  If a court of this state makes an order under paragraph
<span class="subsec">(2)</span>  of subdivision (a), it shall specify in the order a period
that it considers adequate to allow the petitioner to obtain an
order from a court having jurisdiction under the criteria
specified in Chapter 2 (commencing with Section 3421). The
order remains in effect until an order is obtained from the

other court or the period expires.
