# § 3693.

*Part 1 — Definitions And General Provisions · Chapter 6 — Modification,Termination, Or Set Aside Of Support Orders*

When ruling on an action or motion to set aside a support order, the court shall set aside only those provisions materially affected by the circumstances leading to the court’s decision to grant relief. However, the court has discretion to set aside the entire order, if necessary, for equitable considerations. (Added by Stats. 1999, Ch. 653, Sec. 6. Effective January 1, 2000.) FAM Family Code - FAM
