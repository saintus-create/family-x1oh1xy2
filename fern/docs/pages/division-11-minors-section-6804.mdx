# Minors

## Section 6804

<div class="source-note">Back to <a href="/division-11-minors">Division 11: Minors</a></div>

All intangible property owned by the decedent escheats to this state in accordance with <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=6800.">Section 6800</a> if the decedent was domiciled in this state at the time of the decedent’s death.
