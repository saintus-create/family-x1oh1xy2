# 21315 — Application of part to any instrument executed

Pilot Projects

Application of part to any instrument executed
<span class="subsec">(a)</span>  This part applies to any instrument, whenever execut-
ed, that became irrevocable on or after January 1, 2001.
<span class="subsec">(b)</span>  This part does not apply to an instrument that became
irrevocable before January 1, 2001.
