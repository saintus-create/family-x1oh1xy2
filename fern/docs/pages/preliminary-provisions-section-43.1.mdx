---
title: "43.1. a child conceived, but not yet born, is deemed an existing"
description: "A child conceived, but not yet born, is deemed an existing"
slug: preliminary-provisions-section-43.1
---

A child conceived, but not yet born, is deemed an existing
person, so far as necessary for the child’s interests in the
event of the child’s subsequent birth.


[Source](https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=43.1.)
