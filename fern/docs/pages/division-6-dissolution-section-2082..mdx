# § 2082.

*Part 1 — General Provisions · Chapter 7 — Restoration Of Spouse’S Former Name*

This code does not abrogate the common law right of any person to change one’s name. (Amended by Stats. 2024, Ch. 780, Sec. 4. (SB 1150) Effective January 1, 2025.) FAM Family Code - FAM
