# § 412.21 — The word

The word
“judgment” has been substituted
for “decree.”
This is not
a
substantive change. See Section 100 (“judgment” includes decree, as
appropriate).
Subdivision <span class="subsec">(b)</span>  continues without substantive change the fifth
paragraph of subdivision <span class="subsec">(a)</span>  and the second paragraph of subdivision
<span class="subsec">(b)</span>  of former Code of Civil Procedure
