# Preliminary Provisions and Definitions

## Section 15

<div class="source-note">Back to <a href="/preliminary-provisions">Division 1: Preliminary Provisions and Definitions</a></div>

The first sentence also generalizes former Code of Civil Procedure <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1732.">§ 1732</a>, which applied only to conciliation proceedings (former Title 11.5 (commencing with former <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1730.">§ 1730</a>) of the Code of Civil Procedure, now <a href="https://leginfo.legislature.ca.gov/faces/codes_displayText.xhtml?lawCode=FAM&division=5.">Division 5</a> (commencing with <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1800.">§ 1800</a>) of the Family Code). 
The second sentence is a new provision making clear that “shall not” and “may not” are equivalent prohibitory expressions. 
This is not a substantive change. 
[23 Cal.L.Rev.Comm. Reports 1 (1993)].
