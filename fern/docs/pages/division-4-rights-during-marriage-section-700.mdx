# § 700 — Leasehold interest in real property

For the purposes of this division, a leasehold interest in real property is real property, not personal property. _(Enacted by Stats. 1992, Ch. 162, Sec. 10. Operative January 1, 1994.)_ FAMFamily Code - FAM
