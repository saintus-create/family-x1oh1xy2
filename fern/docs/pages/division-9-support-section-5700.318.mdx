# § 5700.318 — A tribunal of this state may:

A tribunal of this state may:

<span class="subsec">(1)</span>  request a tribunal outside this state to assist in obtaining discovery; and

<span class="subsec">(2)</span>  upon request, compel a person over which it has jurisdiction to respond to a discovery order issued by a tribunal outside this state.
