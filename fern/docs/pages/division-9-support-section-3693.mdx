# § 3693 — Set aside of materially affected provisions

Set aside of materially affected provisions
When ruling on an action or motion to set aside a support
order, the court shall set aside only those provisions material-
ly affected by the circumstances leading to the court’s
decision to grant relief. However, the court has discretion to
set aside the entire order, if necessary, for equitable consider-
ations.
