# § 3693 — Set aside of materially affected provisions

When ruling on an action or motion to set aside a support order, the court shall set aside only those provisions materially affected by the circumstances leading to the court’s decision to grant relief. However, the court has discretion to set aside the entire order, if necessary, for equitable considerations. _(Added by Stats. 1999, Ch. 653, Sec. 6. Effective January 1, 2000.)_ FAMFamily Code - FAM4.
