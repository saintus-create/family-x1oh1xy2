# § 3175 — If a matter is set for mediation pursuant to this chapter, the

If a matter is set for mediation pursuant to this chapter, the mediation shall be set before or concurrent with the setting of the matter for hearing. _(Repealed and added by Stats. 1993, Ch. 219, Sec. 116.87. Effective January 1, 1994.)_
