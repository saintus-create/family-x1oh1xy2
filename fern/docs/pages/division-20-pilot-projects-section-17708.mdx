# California Family Code § 17708

<span class="subsec">(a)</span>  This section shall apply to any county that elects to participate in the state incentive program described in Section 17704.

<span class="subsec">(b)</span>  Each participating county child support enforcement program shall provide the data required by Section 17600 to the department on a quarterly basis. The data shall be provided no later than 15 days after the end of each quarter.

<span class="subsec">(c)</span>  On and after July 1, 1998, a county shall be required to comply with the provisions of this section only during fiscal years in which funding is provided for that purpose in the Budget Act.
