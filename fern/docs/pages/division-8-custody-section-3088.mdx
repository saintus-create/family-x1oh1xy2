# 3088. Modification

*Custody of Children*

Modification
of custody order to joint custody
order
An order for the custody of a minor child entered by a
court in this state or any other state may, subject to the
jurisdictional requirements in Sections 3403 and 3414, be
modified
at any time to an order for joint custody in
accordance with this chapter.
