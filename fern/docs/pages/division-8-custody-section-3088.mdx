# 3088

Modification

An order for the custody of a minor child entered by a court in this state or any other state may, subject to the jurisdictional requirements in Sections 3403 and 3414, be modified at any time to an order for joint custody in accordance with this chapter. Amended by Stats. 1993, Ch. 219, Sec. 116.73. Effective January 1, 1994.
