# § 560.

*Part 5 — Remote Marriage License Issuance And Solemnization*

For purposes of this part, “remote technology” means audiovideo technology that is provided by a county clerk and allows the couple, or the couple and others participating in a marriage solemnization, as applicable, to appear together from the same physical location and directly interact with each other and the county clerk. (Added by Stats. 2021, Ch. 620, Sec. 5. (AB 583) Effective October 7, 2021.) FAM Family Code - FAM
