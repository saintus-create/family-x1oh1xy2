# 20036. Pilot project proceedings;

*Pilot Projects*

Pilot project proceedings;
exemption;
judicial
order
Upon motion by either party or on the court’s own motion,
any proceeding that would otherwise fall within this pilot
project may by judicial order be exempted from its require-
ments.
