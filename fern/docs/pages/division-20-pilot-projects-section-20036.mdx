# Pilot Projects

## Section 20036

<div class="source-note">Back to <a href="/division-20-pilot-projects">Division 20: Pilot Projects</a></div>

Pilot project proceedings; exemption; judicial order Upon motion by either party or on the court’s own motion, any proceeding that would otherwise fall within this pilot project may by judicial order be exempted from its requirements.
