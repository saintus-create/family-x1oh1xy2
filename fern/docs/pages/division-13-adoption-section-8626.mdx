# Adoption

## Section 8626

<div class="source-note">Back to <a href="/division-13-adoption">Division 13: Adoption</a></div>

Description of services; disclosure of status An adoption facilitator shall disclose in the first oral communication in which there is a description of services, that the facilitator is not a licensed adoption agency.
