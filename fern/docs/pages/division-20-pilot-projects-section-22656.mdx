# 22656. Judgments

*Pilot Projects*

Judgments
or orders;
effect
No judgment or court order issued pursuant to this chapter
is binding on the system with respect to the Defined Benefit
Program or the Defined Benefit Supplement Program until
the system has been joined as a party to the action and has
been served with a certified copy of the judgment or court
order.
