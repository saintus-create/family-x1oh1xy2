# Minors

## Section 6801

<div class="source-note">Back to <a href="/division-11-minors">Division 11: Minors</a></div>

CODE
<span class="subsec">(1)</span>  The other jurisdiction is entitled to the property under
its law.
<span class="subsec">(2)</span>  The decedent customarily kept the property in that
jurisdiction prior to the decedent’s death.
Real property
Real property in this state escheats to this state in
accordance with Section 6800. (Stats.1990, c. 79 (A.B.759),
§ 14, operative July 1, 1991.)
<span class="subsec">(3)</span>  This state has the right to escheat and take tangible
personal property being administered as part of a decedent’s
estate in that jurisdiction if the decedent customarily kept the
property in this state prior to the decedent’s death. (Stats.
1990, c. 79 (A.B.759), § 14, operative July 1, 1991.)
