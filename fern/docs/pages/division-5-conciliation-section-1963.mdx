# Conciliation Proceedings

## Section 1963

<div class="source-note">Back to <a href="/division-5-conciliation">Division 5: Conciliation Proceedings</a></div>

[7 Cal.L.Rev.Comm. 
Reports 1 (1965)]. 
951 1983 Amendment <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=667.">667</a> is amended to adopt a five-year missing period. 
This period is consistent with Probate Code <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1301.">1301</a> (administration of estates of persons missing five years) and Civil Code Sections 4401(2), 4425(b) (five-year absence in bigamy situations). 
Except for the change in the duration of the missing period from seven to five years, the amendment of <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=667.">667</a> has no effect on the case law interpreting this section. 
[16 Cal.L.Rev-Comm. Reports 105 (1982)].
