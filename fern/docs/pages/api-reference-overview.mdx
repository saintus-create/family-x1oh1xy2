## Family Code API

The **Family Code API** is the machine-readable companion to the interactive Family Code
documentation on this site. It returns the actual codified text of the California Family
Code: divisions, parts, chapters, articles, and sections: exactly as enacted.

## Endpoints at a glance

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/divisions` | List all 20 divisions |
| GET | `/sections` | List sections, filterable by `division` and `part` |
| GET | `/sections/{sectionNumber}` | Fetch one section (e.g. `300`, `4055`) |
| GET | `/search?q=` | Full-text search across the Code |

## Example

<CodeBlocks>
  ```bash title="Get Family Code section 300"
  curl https://api.familycode.ca.gov/v1/sections/300
  ```

  ```json title="Response"
  {
    "sectionNumber": "300",
    "division": 3,
    "part": 1,
    "title": "Marriage is a personal relation / civil contract",
    "text": "Marriage is a personal relation arising out of a civil contract between two persons...",
    enactedBy": "Stats. 1992, Ch. 162, Sec. 10
  }
  ```
</CodeBlocks>

<Note>
  The API is read-only. The enacted Code: and this documentation: remain the source of
  truth. The API simply makes the Code easier to query, cite, and build upon.
</Note>
