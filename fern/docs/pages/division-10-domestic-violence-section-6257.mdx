# 6257. If an emergency protective order concerns an’ endangered

*Prevention of Domestic Violence*

and Institutions Code § 213.5
If an emergency protective order concerns an’ endangered
The fact that the endangered person has left the household
to avoid abuse does not affect the availability of an emergency protective order. (Added by Stats.1993, c. 219 (A.B.1500),
