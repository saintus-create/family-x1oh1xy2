# 1586

ACCEPTANCE MUST BE ABSOLUTE. An acceptance must be

(Enacted in 1872.
144 (A.B. 1847), 2, eff: Jan. 1, 2013.)
ACCEPTANCE MUST BE ABSOLUTE. An acceptance must be
absolute and unqualified, or must include in itself an
acceptance of that character which the proposer can separate
from the rest, and which will conclude the person accepting.
A qualified acceptance is a new proposal. (Enacted in 1872.)
Revocation of proposal; method

10th Contracts 160 (2018), When
Revocation Becomes Effective.
