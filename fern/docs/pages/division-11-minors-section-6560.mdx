# Minors

## Section 6560

<div class="source-note">Back to <a href="/division-11-minors">Division 11: Minors</a></div>

Paragraph (9) is consistent with <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=8440.">§ 8440</a> (waiver of right to appointment by executor). 
Subdivision (b) makes clear that this chapter applies only to the waiver of the rights listed in subdivision (a). The law applicable to the waiver of other rights is not affected by this chapter. 
See, e.g., Civil Code §§ 5200-5317. 
See also <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=80.">§ 80</a> (“Totten trust account” defined). As to pay-on-death accounts, see also <a href="https://leginfo.legislature.ca.gov/faces/codes_displayText.xhtml?lawCode=FAM&division=5.">Division 5</a> 
(commencing with <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=5100.">§ 5100</a>) (multiple-party accounts in financial institutions). 
This chapter has no effect on waivers, agreements, or property settlements made prior to January 1, 1985 (the date this chapter of the repealed Probate Code first became operative).
