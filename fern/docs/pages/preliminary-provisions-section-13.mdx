# Preliminary Provisions and Definitions

## Section 13

<div class="source-note">Back to <a href="/preliminary-provisions">Division 1: Preliminary Provisions and Definitions</a></div>

Severability If a provision or clause of this code or its application to any person or circumstances is held invalid, the invalidity does not affect other provisions or applications of the code which can be given effect without the invalid provision or application, and to this end the provisions of this code are severable.
