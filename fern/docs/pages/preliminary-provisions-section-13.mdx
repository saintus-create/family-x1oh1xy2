# 13

Severability

If a provision or clause of this code or its application to any person or circumstances is held invalid, the invalidity does not affect other provisions or applications of the code which can be given effect without the invalid provision or application, and to this end the provisions of this code are severable. Enacted by Stats. 1992, Ch. 162, Sec. 10. Operative January 1, 1994. FAMFamily Code - FAM
