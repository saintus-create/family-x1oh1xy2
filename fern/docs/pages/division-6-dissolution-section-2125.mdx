# § 2125

*Actions or motions to set aside judgment*

Actions or motions to set aside judgment
When ruling on an action or motion
to set aside a
judgment, the court shall set aside only those provisions
materially affected by the circumstances leading to the court’s
decision to grant relief.
However, the court has discretion to
set aside the entire judgment, if necessary, for equitable
considerations.
