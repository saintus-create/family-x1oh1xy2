Section 3043 continues without substantive change the last sentence of the second paragraph of former Civil Code Section 4600(a).
Section 3043 makes clear that a nomination under the Probate Code
provisions is to be considered and given due weight, regardless of the
nature of the custody proceeding. For background on former Civ.
Code 4600, see Recommendation Relating to Guardianship - Conservatorship Law, 14 Cal. L. Revision Comm’n Reports 501 (1978). [23
Cal.L.Rev.Comm. Reports 1 (1993)].
