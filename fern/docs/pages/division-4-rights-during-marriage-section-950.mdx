# § 950 — Of the Government

The other general provisions of the Code of Civil Procedure
relating to the time within which actions must be commenced—
Sections 350, 351, 353-363—are applicable to actions against public
entities and public employees.
See Williams v. Los Angeles Metro-
politan Transit Authority, 68 Cal.2d 599, 68 Cal.Rptr. 297, 440 P.2d
497 (1968).
See also Government Code Sections 950.2 and 950.4.
Commentary
West Shield Investigations and Security Consultants v. Superior Court,
82 Cal.App.4th 935, 98 Cal.Rptr.2d 612 (2000), holds that this section
has no application to an emancipated minor, because Family Code
§ 7050(e)<span class="subsec">(4)</span>  gives an emancipated minor the right “to sue and be
sued.”
