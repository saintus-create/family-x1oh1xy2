# Preliminary Provisions and Definitions

## Section 7

<div class="source-note">Back to <a href="/preliminary-provisions">Division 1: Preliminary Provisions and Definitions</a></div>

References to statutes; application Whenever a reference is made to a portion of this code or to another law, the reference applies to all amendments and additions regardless of when made.
