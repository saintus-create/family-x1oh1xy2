# § 700

*Leasehold interest in real property*

Leasehold interest in real property
For the purposes of this division, a leasehold interest in
real property is real property, not personal property.
(Stats.
1992,
c.
162 (A.B.2650), § 10, operative Jan.
1, 1994.)
