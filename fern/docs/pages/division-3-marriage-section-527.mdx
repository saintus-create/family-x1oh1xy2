# Marriage

## Section 527

<div class="source-note">Back to <a href="/division-3-marriage">Division 3: Marriage</a></div>

The provisions of Part 4 (commencing with <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=240.">§ 240</a>) of <a href="https://leginfo.legislature.ca.gov/faces/codes_displayText.xhtml?lawCode=FAM&division=2.">Division 2</a> of the Family Code are drawn from and supersede the provisions of Code of Civil Procedure Section 527, insofar as that section formerly applied to these ex parte restraining orders. 
See also <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=210.">§ 210</a> 
(general rules of practice and procedure); Code Civ. Proc. §§ 527(b) 
(section not applicable to this part), 529 (exemption from undertaking requirement). 
[23 Cal.L.Rev.Comm. Reports 1 (1993)].
