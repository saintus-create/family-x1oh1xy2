# Preliminary Provisions and Definitions

## Section 130

<div class="source-note">Back to <a href="/preliminary-provisions">Division 1: Preliminary Provisions and Definitions</a></div>

Separate property 
“Separate property” is property that is separate property under Part 2 (commencing with <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=760.">Section 760</a>) of <a href="https://leginfo.legislature.ca.gov/faces/codes_displayText.xhtml?lawCode=FAM&division=4.">Division 4</a>.
