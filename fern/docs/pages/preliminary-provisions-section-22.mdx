# § 22 — Judicial

Judicial
Council
Section 5206 continues former Civil Code Section 4390(c) without
substantive change. In subdivision (c), the reference to payments
“or” credits was substituted for consistency with subdivision (e). In
subdivision (d), the reference to “[a]ny” payments is omitted as
surplus. This is not a substantive change. [23 Cal.L.Rev.Comm.
Reports 1 (1993)].
