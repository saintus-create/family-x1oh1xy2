# § 25.8 — . The reference to the

. The reference to the
“legal” guardian has been omitted as surplus.
This conforms with
terminology in the Probate Code.
See Prob. Code §§ 2350(b),
2400(b) (“guardian” defined).
[23 Cal.L.Rev.Comm. Reports 1
(1993)].
