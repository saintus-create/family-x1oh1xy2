# California Family Code § 218

With respect to the ability to conduct formal discovery in family law proceedings, when a request for order or other motion is filed and served after entry of judgment, discovery shall automatically reopen as to the issues raised in the postjudgment pleadings currently before the court. The date initially set for trial of the action specified in subdivision <span class="subsec">(a)</span>  of Section 2024.020 of the Code of Civil Procedure shall mean the date the postjudgment proceeding is set for hearing on the motion or any continuance thereof, or evidentiary trial, whichever is later.
