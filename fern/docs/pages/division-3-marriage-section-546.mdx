# Marriage

## Section 546

<div class="source-note">Back to <a href="/division-3-marriage">Division 3: Marriage</a></div>

In subdivision (a), the phrase “by the person against whom the order is sought” has been added. 
This is not a substantive change. 
See Sections 6203 (“‘abuse” defined), 6211 
(“domestic violence” defined). 
See also Sections 6215 (“emergency protective order’ defined), 6240(a) (“judicial officer” defined). 
[23 Cal:L.Rev.Comm. Reports 1 (1993)].
