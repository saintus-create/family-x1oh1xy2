Section 8601 continues former Civil Code Section 221.12 without
substantive change. In subdivision (a), “prospective adoptive parent
or parents” has been substituted for “person adopting a child” for
consistency with the language of subdivision <span class="subsec">(b)</span>  and Sections 8612,
8801, and 8815. As revised, subdivision <span class="subsec">(a)</span>  provides that both
prospective adoptive parents are subject to the 10-year age difference tule. See Section 8542 (“prospective adoptive parent” defined). A reference to “child” has been substituted for “person
adopted.” This is not a substantive change.
In subdivision (b), a reference to “first cousin” has been substituted for “cousin-german.”
This is not a substantive change.
