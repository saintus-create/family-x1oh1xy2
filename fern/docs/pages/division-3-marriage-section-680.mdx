# Marriage

## Section 680

<div class="source-note">Back to <a href="/division-3-marriage">Division 3: Marriage</a></div>

Qualified ownership defined The ownership of property is qualified: 1. When it is shared with one or more persons; 2. When the time of enjoyment is deferred or limited; 3. When the use is restricted. 
(Enacted in 1872.)
