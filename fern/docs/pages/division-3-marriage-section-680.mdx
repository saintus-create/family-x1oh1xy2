# § 680

*Qualified ownership defined*

Qualified ownership defined
The ownership of property is qualified:

PROPERTY
1.
2.
3.
When it is shared with one or more persons;
When the time of enjoyment is deferred or limited;
When the use is restricted. (Enacted in 1872.)
