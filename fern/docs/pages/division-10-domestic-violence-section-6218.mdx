# § 6218 — "Protective order" defined

“Protective order” means an order that includes any of the following restraining orders, whether issued ex parte, after notice and hearing, or in a judgment:

<span class="subsec">(a)</span>  An order described in Section 6320 enjoining specific acts of abuse.

<span class="subsec">(b)</span>  An order described in Section 6321 excluding a person from a dwelling.

<span class="subsec">(c)</span>  An order described in Section 6322 enjoining other specified behavior.
