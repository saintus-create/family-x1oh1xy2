# Support Services

## Section 17309

<div class="source-note">Back to <a href="/division-17-support-services">Division 17: Support Services</a></div>

The notice shall be served on both the support obligor and obligee in compliance with 

§ 4204 <a href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1013.">Section 1013</a> of the Code of Civil Procedure. 
The local child support agency shall file the notice in the action in which the support order was issued.
