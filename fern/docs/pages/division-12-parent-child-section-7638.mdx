# Parent and Child Relationship

## Section 7638

<div class="source-note">Back to <a href="/division-12-parent-child">Division 12: Parent and Child Relationship</a></div>

Procedures to change name of child The procedure in an action under this part to change the name of a minor or adult child for whom a parent and child relationship is established pursuant to <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=7636.">§ 7636</a>, upon application in accordance with Title 8 (commencing with <a class="statute-link" href="https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=FAM&sectionNum=1275.">§ 1275</a>) of Part 3 of the Code of Civil. Procedure shall conform to those provisions, except that the application for the change of name may be included with the petition filed under this part and except as provided in Sections 1277 and 1278 of the Code of Civil Procedure.
