# 7638. Procedures to change name of child

*Parent and Child Relationship*

Procedures to change name of child
The procedure in an action under this part to change the
name of a minor or adult child for whom a parent and child
relationship is established pursuant to Section 7636, upon
application in accordance with Title 8 (commencing with
Section 1275) of Part 3 of the Code of Civil. Procedure shall
conform to those provisions, except that the application for
the change of name may be included with the petition filed
under this part and except as provided in Sections 1277 and
1278 of the Code of Civil Procedure.
