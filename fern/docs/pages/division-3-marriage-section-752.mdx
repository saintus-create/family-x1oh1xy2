# 752

Separate property; interest of parties

Separate property; interest of parties
Except as otherwise provided by statute, neither spouse has
any interest in the separate property of the other.
(Stats.
1992, c. 162 (A.B.2650), 10, operative Jan. 1, 1994. Amend-
ed by Stats.2014, c. 82 (S.B.1306), 15, eff: Jan. 1, 2015.)
