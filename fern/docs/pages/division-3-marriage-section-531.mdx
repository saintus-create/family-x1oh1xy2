# 531 — Application by notary for approval to authorize

Premarital Agreements

Application by notary for approval to authorize
marriage; contents; fees
<span class="subsec">(a)</span>  An application for approval to authorize confidential
marriages pursuant to this part shall be submitted to the
county clerk in the county in which the notary public who is

applying for the approval resides.
The county clerk shall
exercise reasonable discretion
as to whether to approve
applications.
<span class="subsec">(b)</span>  The application shall include all of the following:
<span class="subsec">(1)</span>  The full name of the applicant.
<span class="subsec">(2)</span>  The date of birth of the applicant.
<span class="subsec">(3)</span>  The applicant’s current residential address and tele-
phone number.
<span class="subsec">(4)</span>  The address and telephone number of the place where
the applicant will issue confidential marriage licenses.
<span class="subsec">(5)</span>  The full name
of the applicant’s employer if the
applicant is employed by another person.
