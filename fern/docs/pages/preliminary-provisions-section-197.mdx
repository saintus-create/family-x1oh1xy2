# § 197 — Without

without
substantive change. The reference to the “superior” court has been
omitted as surplus.
See Section 200 (jurisdiction in superior court).
In subdivision (a), the word “unemancipated” has been substituted
for “unmarried.”
This is not a substantive change.
See Section
7002 (conditions of emancipation).
See also Section 3011 (factors to
be considered in determining best interest of child); Code Civ. Proc.
