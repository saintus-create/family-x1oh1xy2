# Legal Reference Components

These custom components replace text-based typography with modern, structured visual elements.

## Section Reference
Replace `§ 300` with:
```mdx
<Section num="300" />
```
Renders as: `Section 300` with a badge

## Statute Citation
Replace `Fam. Code, § 50` with:
```mdx
<StatuteCite code="FAM" section="50" />
```

## Bill Reference
Replace `(AB 1817)` or `(SB 1005)` with:
```mdx
<BillRef type="AB" num="1817" year="2020" />
<BillRef type="SB" num="1005" year="2017" />
```

## Case Citation
Replace `*In re Marriage of Davis* (2015) 61 Cal.4th 846` with:
```mdx
<CaseCite 
  name="In re Marriage of Davis" 
  year="2015" 
  reporter="Cal.4th" 
  volume="61" 
  page="846" 
/>
```

## Definition Term
Replace `"community property"` with tooltip with:
```mdx
<DefinedTerm term="community property">
  Property acquired by either spouse during marriage, owned 50/50
</DefinedTerm>
```

## Legislative History
Replace `*(Amended by Stats. 2019, Ch. 115, Sec. 1.)*` with:
```mdx
<LegislativeHistory>
  <Change year="2019" type="Amended" statute="Stats. 2019, Ch. 115, Sec. 1" effective="January 1, 2020" bill="AB 1817" />
</LegislativeHistory>
```

## Range of Sections
Replace `§§ 300–310` with:
```mdx
<SectionRange from="300" to="310" />
```

## Part/Division Header
Replace text headers with:
```mdx
<DivisionHeader number="3" title="Marriage" sections="300–560" />
```
